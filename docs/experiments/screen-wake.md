# Experiment: screen wake

Command:

```powershell
.\.venv\Scripts\python.exe scripts\monitor.py --device FRG --label screen_wake --duration 60 --all
```

With the display asleep, lift the wrist or press the normal button, wait for the display to turn off, then repeat once. Do not use reset or unusual button combinations.
